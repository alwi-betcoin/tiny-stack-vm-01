An entry for the make.fun bounty [Build a tiny stack virtual machine](https://make.fun/bounty/tiny-stack-vm-01-run-20261122): a faithful interpreter of the tiny stack ISA — 32-bit wrapping integers, 256-value stack, branches, calls, 256 words of memory, input/output, and all ten traps with their exact exit codes.
